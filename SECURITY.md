# Security Policy

Please do not open a public issue for a vulnerability that could expose data,
credentials, authentication state, or a practical exploit. Report it privately
to `lunifans@outlook.com` with the affected version, reproduction conditions,
impact, and any suggested mitigation. Do not include production secrets or
personal data.

Only published releases listed by this repository are supported. A commit on
`main`, an unreviewed pull request, or a mutable container tag is not a release.
